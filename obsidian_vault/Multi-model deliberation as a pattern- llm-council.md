# Multi-model deliberation as a pattern: llm-council

## What it is

karpathy/llm-council (~24k stars) puts several models to work on the same hard question and has them deliberate rather than trusting a single response. autoresearch (~94k) applies the same instinct to research, running agents that conduct ML experiments against nanochat training automatically.

## Why it matters

This is the same architecture as the antigravity-council setup already on this machine - so llm-council is a reference implementation to compare against rather than a novelty.
