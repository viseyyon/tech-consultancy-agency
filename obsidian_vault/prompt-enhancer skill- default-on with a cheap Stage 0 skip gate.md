# prompt-enhancer skill: default-on with a cheap Stage 0 skip gate

## What it is

The prompt-enhancer skill runs silently by default -- the user sees only the improved answer, never the raw enhancement step -- after all five council models warned against an unconditional always-on pipeline. A Stage 0 cheap-skip gate decides whether enhancement is worth the cost per request. An early directional A/B evaluation (n=6) showed 3 wins, 3 ties, 0 losses against the unenhanced baseline.

## Why it matters

Documents the shipped default behavior and the small, still-thin evidence base behind it.
