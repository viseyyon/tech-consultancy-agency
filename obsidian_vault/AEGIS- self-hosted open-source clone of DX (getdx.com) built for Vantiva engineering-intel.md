# AEGIS: self-hosted open-source clone of DX (getdx.com) built for Vantiva engineering-intelligence measurement

## What it is

AEGIS is a self-hosted, $0-per-seat open-source clone of DX (getdx.com) built for Vantiva engineering-intelligence measurement, replicating DX's Core 4 framework (Speed, Effectiveness, Quality, Impact) on a FastAPI backend, React/Recharts frontend, PostgreSQL, Redis, Celery, and GitHub/GitLab/Jira/Claude Code CLI integrations. It was built after evaluating DX's Claude Code connector and uses DX's own formula (1 DXI point = 13 min/dev/week saved) to project ~$750K+ annual value per 5-point DXI improvement for a 200-engineer org.

## Why it matters

A built but not-confirmed-deployed internal alternative to a paid DX subscription; its projected value case ($750K+ per 5 DXI points) is useful ammunition if pitching adoption, but deployment status must be verified before citing it as live.
