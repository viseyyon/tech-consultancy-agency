# AI-agent-friendly engineering convention templates

## What it is

ai-ready-project-conventions and awesome-ai-conventions both offer naming, architecture, git, and auth convention templates written specifically so coding agents like Claude Code, Cursor, and Codex produce more consistent output across a codebase.

## Why it matters

Adopt one of these when an agent's output style or structure is inconsistent across a team or repo and a documented convention set is preferable to ad hoc prompting.
