# TechnoKarZ: React Native + Firebase car-repair app for Chennai, sold via a phased incremental pitch

## What it is

TechnoKarZ is a full-stack venture prototype (customer app, mechanic app, admin web portal) for a Chennai car-wash/repair/service business, covering vehicle registration, real-time repair-stage tracking, mechanic photo documentation, booking flow, and a payment-gateway placeholder on Firebase. Go-to-market was explicitly incremental: each delivery phase (customer app, mechanic tools, admin/analytics) priced separately at roughly ₹150,000–250,000 to keep upfront customer investment low while proving value phase by phase.

## Why it matters

This is the same 'minimal upfront cost, prove value in phases' pattern used elsewhere in Surendran's sales pitches, worth reusing for future venture pitches.
