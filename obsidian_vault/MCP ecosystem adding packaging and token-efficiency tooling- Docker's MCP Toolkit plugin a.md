# MCP ecosystem adding packaging and token-efficiency tooling: Docker's MCP Toolkit plugin and 'Token Saver'

## What it is

Docker (Oct 2025) announced its MCP Toolkit can be installed as a Claude Code plugin, letting Claude reach any MCP server in Docker's catalog from a sandboxed container. Separately, 'Token Saver' (Jul 2026, via Marktechpost) is an open-source MCP extension using local hybrid RAG that claims a 90-99% cut in Claude's PDF-handling token costs.

## Why it matters

Two concrete integration options for MCP deployments — containerized MCP server management, and a local-RAG approach to document token costs — but the 90-99% figure is a press-release claim, unverified here.
