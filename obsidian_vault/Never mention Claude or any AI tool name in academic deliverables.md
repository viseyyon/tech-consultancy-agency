# Never mention Claude or any AI tool name in academic deliverables

## What it is

Across MLOps, EDA, and CNN coursework, the user requires notebooks, reports, checklists, READMEs, push scripts, and even document metadata (e.g. Word's app.xml) to be scanned clean of "Claude", "Anthropic", "ChatGPT", "Copilot", "Gemini", and AI-sounding phrasing before anything is called submission-ready.

## Why it matters

A stray AI-tool reference or AI-sounding phrase in a graded academic submission risks an academic-integrity flag, the one failure mode this rule exists to prevent.
