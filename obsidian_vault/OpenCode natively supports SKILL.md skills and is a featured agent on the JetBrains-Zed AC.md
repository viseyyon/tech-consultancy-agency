# OpenCode natively supports SKILL.md skills and is a featured agent on the JetBrains/Zed ACP registry

## What it is

OpenCode's skill system uses the same SKILL.md on-demand-load pattern as Claude's own skills directory. It ships typed built-in agents (Build/Plan/Research/Explorer) plus custom Markdown-defined agents, and is listed as a featured agent in the ACP (Agent Client Protocol) registry launched by JetBrains and Zed -- an open standard letting agents install directly inside IDEs, akin to LSP for AI agents.

## Why it matters

A competing agent tool now shares Claude's skill-loading pattern and is officially featured in a cross-IDE agent registry, relevant industry context for evaluating alternative agent tooling.
