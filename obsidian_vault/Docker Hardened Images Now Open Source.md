# Docker Hardened Images Now Open Source

## What it is

Docker released over 1,000 'Docker Hardened Images' (minimized, security-hardened base images) as open source under Apache 2.0, previously a more closed/commercial offering.

## Why it matters

Relevant default choice for base images in any deployment, including self-hosted agent/RAG infra, that wants a smaller attack surface without building hardened images in-house.
