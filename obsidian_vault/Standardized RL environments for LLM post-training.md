# Standardized RL environments for LLM post-training

## What it is

Hugging Face's OpenEnv defines a Gym-like standardized interface for RL training environments aimed at LLM agents, and its companion Repo2RLEnv converts an arbitrary code repository directly into one of those environments.

## Why it matters

Use these when setting up an RL post-training pipeline against real code instead of hand-building a bespoke environment interface.
