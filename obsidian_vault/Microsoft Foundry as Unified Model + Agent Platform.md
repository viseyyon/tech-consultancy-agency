# Microsoft Foundry as Unified Model + Agent Platform

## What it is

Microsoft Foundry bundles a model catalog, published pricing, and platform-level role-based access control (RBAC) for governing who can deploy or manage models and agents within an org - positioned as the enterprise control-plane layer, not just a model API.

## Why it matters

Relevant when comparing 'raw model API' vendors against platform vendors that also handle access governance out of the box.
