# Infra vendors give away the base runtime and pitch the orchestration/control layer as the real product

## What it is

At Build 2026, Microsoft launched 'Scout' on the open-source OpenClaw agent runtime, explicitly framed as making the runtime free while keeping the surrounding control plane as the product; separately Runpod's 'Flash' (May 2026, GA) is an open-source Python tool eliminating containers for AI deployment, pitched as Runpod's shift from selling raw compute to selling an orchestration layer.

## Why it matters

Recognizable current GTM pattern in AI infra: commoditize the base runtime/compute primitive, monetize the layer that manages it — useful lens when evaluating a new infra vendor's pricing story.
