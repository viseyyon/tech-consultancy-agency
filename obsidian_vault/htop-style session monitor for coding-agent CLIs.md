# htop-style session monitor for coding-agent CLIs

## What it is

graykode/abtop is a terminal dashboard that shows live Claude Code and Codex CLI session stats: tokens used, context-window fill, rate limits, and open ports, across concurrent sessions.

## Why it matters

Useful when running several coding-agent sessions at once and needing an at-a-glance resource view instead of checking each terminal.
