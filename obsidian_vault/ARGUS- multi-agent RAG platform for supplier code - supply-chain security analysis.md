# ARGUS: multi-agent RAG platform for supplier code / supply-chain security analysis

## What it is

ARGUS is Surendran's Embedded OEM Code & Supply-Safety Analysis Platform: a FastAPI/React-TypeScript app on PostgreSQL/TimescaleDB using specialized AI agents (Security Analyst, Code Reviewer, Remediation Expert) with a RAG pipeline over Chroma/Pinecone/FAISS for semantic code search. It supports five analysis depths (30-second quick scan to 30-minute deep research) across C/C++, Java/Kotlin, Python, JS/TS, Go, Rust, and binary analysis (binwalk/Ghidra), outputting a 'Supplier Trust Score,' with Kubernetes deployment and Prometheus monitoring planned.

## Why it matters

A named, reusable platform for supplier code and supply-chain security audits that should be recognized as prior work rather than rebuilt from scratch.
