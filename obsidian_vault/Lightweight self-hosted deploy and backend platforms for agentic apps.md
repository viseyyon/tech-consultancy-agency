# Lightweight self-hosted deploy and backend platforms for agentic apps

## What it is

InsForge is an all-in-one backend-as-a-service, covering database, auth, storage, compute, hosting, and AI gateway, marketed at agentic coding workflows; basecamp/once and openberth are both minimal, dependency-light self-hosted deploy tools that take source code and return a live HTTPS URL, in the spirit of a self-hosted Heroku or Railway.

## Why it matters

Reach for these instead of a full PaaS subscription when a coding agent needs to deploy its own output to a real URL without hand-provisioning cloud infrastructure.
