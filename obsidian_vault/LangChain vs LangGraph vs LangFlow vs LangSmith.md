# LangChain vs LangGraph vs LangFlow vs LangSmith

## What it is

A clarifying distinction: LangChain is the base library of LLM building blocks, LangGraph is the graph/state-machine layer for multi-step or multi-agent control flow, LangFlow is a visual/no-code builder on top of LangChain, and LangSmith is the observability/tracing/eval product for debugging chains and agents in production.

## Why it matters

The four names get used interchangeably by newcomers but solve different problems, so picking the wrong one wastes setup time.
