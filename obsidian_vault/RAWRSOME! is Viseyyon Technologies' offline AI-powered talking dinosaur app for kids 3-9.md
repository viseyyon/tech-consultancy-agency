# RAWRSOME! is Viseyyon Technologies' offline AI-powered talking dinosaur app for kids 3-9

## What it is

RAWRSOME! is Viseyyon Technologies' offline AI-powered talking dinosaur app for kids 3-9 (package com.viseyyon.rawrsome), with four characters (Rex, Brachi, Trixie, Pteranodon) offering Talking-Tom-style plush interactions. It runs on-device via Google Gemma 3n-2B INT4 through the MediaPipe LLM Inference API instead of a cloud Claude API call, for zero API cost, offline operation, and privacy as a parental-trust signal; the ~1.1GB model needs a 4GB+ RAM Android device and must be hosted on Viseyyon's own CDN since Kaggle URLs can't be used in production.

## Why it matters

Built via a two-part Claude Code prompt (base build + Gemma offline addendum) plus a dedicated brand-patch file, so the design pattern (cloud-prompted, on-device-deployed) is reusable for other Viseyyon consumer apps.
