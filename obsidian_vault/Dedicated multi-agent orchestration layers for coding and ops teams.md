# Dedicated multi-agent orchestration layers for coding and ops teams

## What it is

Tools like Squad, COMPASS, LangGraph, and the 'agent-as-tool' pattern in OpenAI's Agent SDK wrap several specialized agents behind a coordinator that dispatches subtasks to whichever agent fits.

## Why it matters

Useful once a single agent's context or skill set can't cover an end-to-end task, e.g. triaging bug reports across a whole codebase.
