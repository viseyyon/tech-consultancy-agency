# SYNTHFORCE-OC is positioned as internal engineering infrastructure, not a generative AI tool

## What it is

Under legal review triggered by the Broadcom SLA letter, SYNTHFORCE-OC was reframed away from AUP section 2.9 (generative AI tool governance) to AUP section 2.3/2.6 (internal engineering infrastructure): it is a context engine + agent runtime + skills catalogue + MCP server registry that invokes approved Microsoft Azure inference, not an LLM or model provider itself.

## Why it matters

This reframing is legally and operationally material — it changes which policy governs the platform and avoids the vendor-restriction overlay gap that would otherwise apply to a section 2.9 tool.
