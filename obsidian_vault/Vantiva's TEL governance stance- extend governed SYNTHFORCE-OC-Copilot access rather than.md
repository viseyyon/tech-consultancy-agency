# Vantiva's TEL governance stance: extend governed SYNTHFORCE-OC/Copilot access rather than let partners run unvetted AI

## What it is

For partner org TEL's request for Vantiva AI tooling access, the recommended stance was to approve a small governed pool of 5-10 GitHub Copilot seats under chargeback, extend the existing governed SYNTHFORCE-OC access model for Jira/RCA use cases instead of new tooling, and flag Kavia.ai for security/compliance review since it is not on Vantiva's approved tooling list.

## Why it matters

Blocking TEL outright risked them running unvetted AI against Vantiva's codebase, so governed extension was chosen as the lower-risk path, directly modeled on the AIRLOCK/Broadcom precedent.
