# MCP's host/client/server model and its adoption curve

## What it is

MCP is explained as three parts: a host application (Claude Desktop, Cursor, ChatGPT), an embedded client, and a server exposing tools/resources/prompts discovered at runtime; monthly SDK downloads are reported growing from roughly 100K to 97M in about 18 months.

## Why it matters

Core mental model for building or evaluating any MCP integration; treat the growth figure as order-of-magnitude, single-source.
