# Canonical agentic design pattern catalog

## What it is

Multiple guides converge on the same core pattern set for building agents: prompt chaining, routing, reflection, tool use, planning, and multi-agent composition, with human-in-the-loop and memory as supporting layers.

## Why it matters

Gives a shared vocabulary for designing or evaluating any agent system instead of reinventing structure ad hoc.
