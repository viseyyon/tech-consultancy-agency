# Engineering Intelligence Platform v2: council-vetted 28-week plan

## What it is

Engineering Intelligence Platform v2 is a council-vetted, 28-week build plan using a Kafka/Redpanda event backbone, AST-aware diffing instead of raw SZZ, semantic routing, Gitleaks/TruffleHog for code egress scanning, and a P0 canonical entity-resolution layer treated as the dominant risk. Prophet was dropped from the design and distillation work is deferred behind evaluation gates. A v3 upgrade round (CI/CD and test-intelligence pillar, JIT defect-prediction scores feeding SYNTH-REVIEW, an MCP-native serving layer, prompt-injection screening at ingestion) is drafted but council ratification was interrupted mid-review and still needs to be re-run.

## Why it matters

Tracks both the accepted v2 architecture and the specific v3 additions still awaiting council sign-off.
