# Dashboard Prompt Pattern With Inferred Narrative Notes

## What it is

A working prompt pattern for building a financial variance dashboard: ask for actuals-vs-budget at both monthly and quarterly granularity in one build, and explicitly instruct the model to add narrative notes inferred from transaction memos rather than just rendering the numbers.

## Why it matters

The 'infer narrative from memos' instruction is the reusable part - it turns a plain numeric dashboard into one with explanatory context.
