# Vantiva's three mandatory gates for AI-generated code: IP legal, COSP open-source assessment, and security

## What it is

Every AI-generated code artefact at Vantiva must clear three tollgates before merge: IP legal (non-infringement), COSP (open-source assessment), and security (vulnerability-free). Use cases are risk-tiered (HIGH/MEDIUM/LOW) across six R&D domains (Code Generation, Code Review, Debugging/RCA, Test Automation, Knowledge Management, Software Quality), with internal SYNTHFORCE-OC tools (SYNTH-REVIEW, SYNTH-RCA, SYNTH-PATCH, GraphRAG) and external tools (Copilot for Business, Jenkins, Gerrit, FOSSA, Snyk, SonarQube, Dependabot, Jira) mapped to each gate.

## Why it matters

This was submitted as the AI CoE's contribution to an internal AI-safety compliance assessment, so it is the authoritative gate structure leadership expects any AI-code workflow to satisfy.
