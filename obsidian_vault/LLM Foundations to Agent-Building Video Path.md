# LLM Foundations to Agent-Building Video Path

## What it is

A sequenced free video route: 3Blue1Brown's high-level intuition on how LLMs work, then Karpathy's 'Deep Dive into LLMs like ChatGPT' for the training/inference pipeline, then his from-scratch build videos ('Let's build GPT' then 'Let's build the GPT Tokenizer') to see the internals in code, then his 'How I use LLMs' for practical usage. From there: Dave Ebbelaar's single-file breakdown of an agent loop, a RAG crash course (Krish Naik's LangChain RAG course or KodeKloud's RAG Tutorial), and a design-patterns reference (Krish Naik's LangGraph+MCP course or the Agentic Design Patterns book) to generalize from toy agents to reusable architectures.

## Why it matters

Gives a coherent zero-to-agent-builder progression instead of jumping into framework tutorials without understanding the underlying model.
