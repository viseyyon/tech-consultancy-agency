# The Emerging Agentic Web Stack

## What it is

Microsoft's Agent Factory series frames a forming 'agentic web stack' - layered, interoperable standards for identity, discovery, memory and tool protocols - that would let agents from different vendors work together, echoing how MCP/A2A-style protocols are being positioned.

## Why it matters

Signals that architecture decisions should favor standard protocols over bespoke agent-to-agent glue if this framing plays out.
