# MedHELM: Clinical Task Evaluation Framework

## What it is

MedHELM (published in Nature Medicine) is an extensible LLM evaluation framework purpose-built for medical tasks, contributing both a taxonomy for classifying clinical task types and a benchmark spanning many datasets within that taxonomy, rather than relying on generic QA benchmarks for clinical claims.

## Why it matters

The right reference when evaluating an LLM or agent for a healthcare use case, since generic benchmarks like MMLU don't capture clinical-task performance well.
