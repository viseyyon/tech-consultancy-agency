# The Phi-4 SDK-specialist assistant plan descends from earlier named attempts: Selen, Selenia, QuantumMesh AI

## What it is

Between May 28 and June 8, 2025, the same underlying system was repeatedly proposed under different names: fine-tune qwen2.5-coder:14b on Gerrit commits + JIRA bugs + SOC/SDK docs ('Selen'/'Selenia'), a Mixture-of-Experts variant with per-task expert routing ('QuantumMesh AI'), and several unnamed 'AI Developer Framework' builds for RDK/OpenWrt/Android with auto-commit capability.

## Why it matters

This recurring goal — an autonomous coding agent trained on the org's own Gerrit/JIRA/SDK history — is the direct precursor to the later, more settled Phi-4 14B Broadcom/Qualcomm SDK specialist plan, so new requests in this shape should be recognized as continuations, not fresh ideas.
