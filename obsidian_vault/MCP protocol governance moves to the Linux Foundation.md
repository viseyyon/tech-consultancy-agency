# MCP protocol governance moves to the Linux Foundation

## What it is

The Model Context Protocol is moving under Linux Foundation governance, shifting it from a single-vendor-steered spec toward a neutrally-governed open standard.

## Why it matters

Matters for anyone building on MCP long-term, since neutral governance affects spec stability and cross-vendor trust.
