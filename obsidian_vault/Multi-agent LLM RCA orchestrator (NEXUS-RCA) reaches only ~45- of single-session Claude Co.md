# Multi-agent LLM RCA orchestrator (NEXUS-RCA) reaches only ~45% of single-session Claude Code RCA quality

## What it is

Benchmarked a 5-LLM-provider (Claude, GPT-4, Gemini, Grok, Azure OpenAI) multi-agent RCA orchestrator (NEXUS-RCA) against a reference 1,843-line RCA report generated by a single Claude Code session. Finding: Claude Code alone already exhibits semantic reasoning, causal hypothesizing, and epistemic honesty (explicit confidence levels, stated data limitations) that traditional ML log-analysis pipelines can't replicate; the multi-agent orchestrator currently reproduces only ~45% of that quality, with ~60 engineering-hours over 4 weeks (plus a dedicated CodeForensics agent) estimated to reach ~90% parity.

## Why it matters

This is a concrete benchmark showing multi-agent orchestration underperforms single-session Claude Code for RCA quality, so a multi-agent RCA claim should not be assumed superior without this gap in mind.
