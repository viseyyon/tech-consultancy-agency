# Wants an architecture diagram plus a companion detail doc per project

## What it is

For substantial projects, the user expects a rendered layered architecture diagram together with a companion document covering per-layer component rules, state tables with concurrency semantics, and deployment notes, saved into the project folder as a deliverable rather than just described in chat.

## Why it matters

Skipping the diagram/doc pair leaves the project without the reference artifact the user explicitly treats as a required deliverable.
