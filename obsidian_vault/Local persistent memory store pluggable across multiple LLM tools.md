# Local persistent memory store pluggable across multiple LLM tools

## What it is

CaviraOSS/OpenMemory is a local, persistent memory store designed to plug into several different LLM tools, including Claude Desktop, GitHub Copilot, Codex, and Antigravity, rather than being tied to one assistant.

## Why it matters

Fills the gap when an assistant has no built-in long-term memory and a per-tool memory silo is undesirable.
