# Multi-agent fleet coordination frameworks

## What it is

A wave of frameworks (Google's Sovereign Agent Mesh, Multica, OpenGoat, OpenOffice, CUGA) let a user assign tickets or tasks to a pool of coding agents (Claude Code, Codex, Cursor, etc.) and have them work as a coordinated team with shared visibility into each other's work.

## Why it matters

Reach for one of these when a single agent session is not enough and several agents or tool backends need to work the same codebase or task queue concurrently.
