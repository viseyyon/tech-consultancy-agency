# multica assigns issues to 20+ coding agents as if they were teammates

## What it is

An open-source, self-hostable Go service that dispatches issues to Claude Code, Codex, Cursor and around seventeen other coding agents, treating each as an assignable worker. Roughly 47,000 stars and pushed the same day it was reviewed, so actively maintained.

## Why it matters

This is the missing orchestration layer if you want several coding agents working a backlog rather than one agent in one terminal - and self-hosting keeps the code on your own infrastructure.
