**Enterprise-grade automated technology consultancy powered by 5 specialized AI agents**

## 🎯 What It Does

Analyzes any GitHub repository and generates professional consultancy reports in seconds:

- **Technology Assessment** - Stack analysis, maturity scoring (1-10)
- **Business Value Analysis** - ROI calculation, use cases, competitive positioning  
- **Integration Strategy** - Implementation planning, effort estimates
- **Obsidian Integration** - Auto-updates knowledge base with analysis findings

## 🤖 Multi-Agent System

This application uses **5 specialized AI agents** working in concert:

1. **🔍 Deep Research Agent**
   - URL validation & security checks
   - Content fetching with retry logic
   - Metadata extraction (stars, forks, contributors)

2. **🔧 Technology Assessor**
   - Technology stack analysis
   - Maturity scoring (1-10 scale)
   - Architecture pattern identification
   - Risk assessment

3. **💼 Business Value Analyzer**
   - Use case identification
   - ROI calculation & payback period
   - Competitive positioning analysis
   - Benefit quantification

4. **🏗️ Integration Strategist**
   - Integration architecture design
   - Effort estimation (hours/weeks)
   - Phased rollout planning
   - Risk mitigation strategies

5. **📊 Report Synthesizer**
   - Professional report generation
   - Obsidian vault integration
   - Knowledge base updates
   - Multi-format export (MD, JSON)

## 🏗️ Architecture

```
URL Input → Deep Research Agent → Technology Assessor 
          → Business Value Analyzer → Integration Strategist 
          → Report Synthesizer → Deliverables
```

**Deliverables**:
- Professional consultancy report (Markdown)
- Structured findings (JSON)
- Obsidian vault note (with frontmatter & wikilinks)
- Repository index update
